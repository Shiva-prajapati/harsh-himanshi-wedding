# Royal Wedding Invitation — Harsh & Himanshi 🪷

An ultra-premium, interactive 3D Indian royal wedding invitation website built with **React 18**, **Three.js**, **React Three Fiber (R3F)**, **Drei**, and **GSAP**.

---

## 👑 Features

- **Scene 1: Royal Palace Gateway**
  - Procedurally modeled grand archway with fluted columns, ornate gold crowns, and flickering diya oil lamps.
  - Double maroon-velvet doors with gold trims that swing open on tap or auto-advance with royal temple chimes.
- **Scene 2: Sacred Invitation Card**
  - Realistic ivory textured card in 2:3 proportion with gold embossed foil borders and corner motifs.
  - Smooth GSAP 3D entrance and gentle floating idle animation.
  - Traditional Vedic shloka & opening quote from the card.
- **Scene 3: Couple Reveal & Lineage**
  - Side-by-side ornate circular gold frames for **Harsh Prajapati** & **Himanshi Prajapati**.
  - Complete ancestral lineage and parents' blessings.
  - Central sacred knot medallion connecting the frames.
- **Scene 4: Auspicious Celebrations & Programme**
  - Fanned out 3D ivory slabs for all 4 wedding ceremonies:
    1. 🎵 **Ladies Sangeet** — Tuesday, 18 Nov 2026 (8:00 PM)
    2. 🕍 **Mandap & Ghurchari** — Wednesday, 19 Nov 2026 (Mandap 10:00 AM, Lunch 12:00 Noon, Ghurchari 9:00 PM)
    3. 💍 **Departure of Barat** — Thursday, 20 Nov 2026 (5:00 PM from Sadholi Kadeem)
    4. 🎊 **Wedding Reception** — Thursday, 20 Nov 2026 (Shiva Banquet Hall, Saharanpur)
- **Scene 5: Venue & RSVP**
  - Night sky starfield with majestic palace silhouette backdrop.
  - Three interactive CTA actions:
    - 📍 **View Location**: Direct Google Maps navigation to Shiva Banquet Hall, Shakumbhari Vihar.
    - 📞 **Confirm Presence**: Direct WhatsApp confirmation to Master Ramswaroop Prajapati.
    - 🙏 **Send Blessings**: Interactive blessings form triggering royal gold & rose petal confetti!
  - Scrollable RSVP and W.K.C.S. (Youth & Relatives) sections.
- **Atmospheric Particle Systems**
  - Drifting pink rose petals with fluttering physics.
  - Sparkling gold dust rain with additive blending.
- **Audio Synthesizer (Web Audio API)**
  - Procedural Indian classical tanpura drone in D major and bansuri/shehnai melodies in Raga Yaman.
  - No external MP3 downloads required — zero network dependencies and 100% offline reliability.
- **Performance & Accessibility**
  - Automatic device tier detection (`high` / `mid` / `low`) adjusting particle counts and shadows.
  - Full `prefers-reduced-motion` compliance.
  - Full 2D HTML fallback mode for non-WebGL devices or instant classical reading.
  - Mobile touch swipe navigation.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
